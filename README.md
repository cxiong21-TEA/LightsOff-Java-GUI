# LightsOff Java GUI

A Java desktop game inspired by the classic Lights Out puzzle.

## Overview

This project was developed for a Data Structures and Java course using Visual Studio Code. The application uses a graphical user interface built with Java Swing and AWT.

Players interact with a grid of lights by clicking cells. Each move changes the state of the selected light based on the game logic, and the interface tracks moves and completed games.

## Features

- Java graphical user interface using Swing and AWT
- Interactive grid with mouse-click controls
- Multiple game boards
- Move tracking
- Win tracking
- Dynamic board rendering
- New Game button for switching between boards
- Visual indication of light states
